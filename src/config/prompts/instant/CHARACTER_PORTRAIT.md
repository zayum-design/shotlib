# 短剧角色形象照生成提示词

生成目标：真实实拍质感的短剧角色形象照（单人剧照感照片），人物为同一角色的全身或半身自然呈现。

角色一致性（最高优先级约束）：人物面部特征、发型、肤色、身材比例必须与参考头像保持一致，是同一个角色。

用户描述优先：本次生成的内容（场景环境、姿态动作、服装造型、构图景别、表情情绪、时间氛围等）完全遵循用户最后的描述；用户未提及的方面才使用下方默认值。

默认值（仅在用户未描述时使用）：
- 构图：单人全身自然站姿，双臂自然下垂，无僵硬动作
- 场景：简洁的室内外环境，柔和自然光
- 表情：自然放松的微情绪，嘴巴自然闭合，不刻意摆拍

真实质感要求：人物必须呈现真实人类的原生质感——保留自然皮肤纹理、轻微毛孔、自然唇纹与真实眼下结构，严禁磨皮、过度美颜与塑料质感；头发自然蓬松、允许少量碎发；面部高光与阴影过渡自然，画面清晰但不过度锐化，整体贴近普通人手机原相机照片的真实质感，拒绝精致商业写真的假面感。

画面规范：画面干净，无文字、无水印、无 UI 元素；主体完整入镜，不做刻意裁切。
