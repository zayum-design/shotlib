# 修改原则
1. 严格按修改要求执行，只修改与要求相关的提示词，其余保持原样
2. 修改后的提示词仍须与剧本正文的情节、台词、人物保持一致
3. 画面类提示词必须是具象可视觉化的描述；视频提示词须包含明确的动作与运镜描述；风格与原提示词保持一致
4. 结构化标签必须完整保留，不得删除标签或改动标签文本；标签的属性值（character-id、portrait-index、scene-id）必须原样保留——**仅当属性值本身与【角色清单】不符时（如 @<portrait> 的 character-id 指向了错误的角色），才修正为清单中的正确值**
5. 只输出需要修改的片段/分镜及其需要修改的字段，未修改的不要输出
6. id 必须与输入中的片段 id / 分镜 id 完全一致，不得编造
7. **片段数量调整（拆分/合并/删减）**：当修改要求涉及片段数量变化时：
   - **新增片段**：在 episodes 数组中输出完整的新片段对象，id 用 `__new__` 前缀（如 `__new__1`、`__new__2`），必须包含 title、description、shots（完整分镜数组，分镜 id 同样用 `__new__` 前缀）、firstFramePrompt、lastFramePrompt、firstLastFrameVideoPrompt；新片段从原片段拆分而来时，须保持与原片段首尾帧的连续性承接。**新片段所有 shots 的 `duration` 之和严禁超过本剧片段时长上限**（默认 15 秒，长片段模型 30 秒——视频生成模型硬上限，超限会导致生成失败或尾部镜头被截断）：输出前必须逐个相加验算，若超出，优先压缩过渡性分镜的时长（高潮/对白分镜优先保留），绝不允许带超限时长输出
   - **删除片段**：输出 `{"id": "<原片段id>", "deleted": true}`
   - 新增/删除片段时须同步重排相邻片段的衔接关系（上片段尾帧与新增片段首帧、新增片段尾帧与下片段首帧的连续性）
7. **镜头合同（修改分镜 prompt 时仍须满足）**：单镜只承载一个主体动作 + 一个主要运镜；写清结束帧画面状态，且与下一分镜开头状态承接；对白仍以 `{对白}` 格式嵌入（配表情/手势/头部动作，严禁口型机械描述），禁止省略或新增剧本外台词
8. **片段间连续性（修改首/尾帧或首尾分镜时仍须满足）**：片段的 lastFramePrompt 与下一片段的 firstFramePrompt 必须在场景/时间/人物位置姿势/道具/光线/情绪上互相承接；修改任何一端时同步检查另一端，禁止只改一端造成新的断裂；换场只能发生在片段边界且需过渡描述
9. **首尾帧契约（修改 frame 类 prompt 时仍须满足）**：firstFramePrompt / lastFramePrompt 为纯静态定格画面，严禁动态词、对白、运镜；firstLastFrameVideoPrompt 用视觉特征指代人物，`{}` 外严禁角色姓名与代词，必须嵌入真实对白
10. **反 AI 味**：修改后的提示词禁止抽象情绪副词（「X地说」「神色复杂」「气势逼人」）与 AI 腔套话，情绪一律翻译为嘴唇、下巴、眼神、肩膀等可见细节；末尾画面约束（无字幕/无水印/背景人群虚化）不得丢失

只输出一个 JSON 对象，不要输出任何解释或 markdown 代码块标记。格式如下：

      "firstFramePrompt": "修改后的首帧提示词（仅在需要修改时输出此字段）",
      "lastFramePrompt": "修改后的尾帧提示词（仅在需要修改时输出此字段）",
      "firstLastFrameVideoPrompt": "修改后的首尾帧视频提示词（仅在需要修改时输出此字段）",

          "id": "分镜id",
          "prompt": "修改后的分镜提示词（仅在需要修改时输出此字段）",
          "referencePrompt": "修改后的分镜参考图提示词（仅在需要修改时输出此字段）"

      "deleted": true
    },
    {
      "id": "__new__1",
      "title": "新片段标题（≤15字）",
      "description": "新片段的完整自含概述（场景人物/动作冲突/对白要点/状态变化/结尾定格）",
      "shots": [
        {
          "id": "__new__1_s1",

          "cameraAngle": "eye_level",
