# 角色字段规范（与剧本解析完全一致，逐条遵守）

- name: 角色名（字符串）。若缺失角色属于某人物的年龄阶段拆分（剧本中同一人不同年龄段），命名必须为「姓名-年龄段」，年龄段取：童年（≤12）/ 少年（13-17）/ 青年（18-35）/ 中年（36-59）/ 晚年（≥60）；普通角色直接用剧本中的姓名
- gender: 性别（男/女）
- age: 年龄（字符串，如 "25岁"、"8岁"；写剧本中该角色出场时的实际年龄）
- description: 角色描述（性格、职业、外貌等；不应再包含性别和年龄；若是拆分角色，描述体现该年龄段的身份状态和性格特点）
- avatarPrompt: 生成角色头像的提示词（字符串）。**必须以明确的所属年代+年龄+国别+性别开头**，如 "上世纪80年代60岁中国男性，..."。**必须包含极其详细的长相描述**，涵盖：1) 性别（最前端明确男性/女性）；2) 脸型轮廓；3) 眼睛特征；4) 鼻子特征；5) 嘴唇特征；6) 眉毛特征；7) 发型发色；8) 肤色；9) 特殊标记（痣/疤痕/酒窝等，不含皱纹）。**严禁包含任何表情、情绪、神态等感情因素**（头像为中性、无情绪状态）。**严禁包含任何临时状态或动态身体细节**（如"头发凌乱"、"双手粗糙"等）。每个角色的特征组合必须独一无二，严禁与其他角色雷同
- imagePrompt: 生成角色全身图片的提示词（字符串，基于头像生成，头部特征已由头像决定）。**必须以明确的所属年代+年龄+国别+性别开头**。**必须包含详细的人物身体描述**：身材体型、身高体态、穿着服装、鞋履状态。**严禁包含任何头部相关描述**（发型、发色、头饰、面部特征等）。**严禁包含任何场景、背景、环境描述**（纯白背景、标准站立姿势）。**严禁包含任何表情、情绪、神态**。**严禁包含任何剧情临时状态或动作描述**（如"袖口挽起"、"衣角沾血"）

# 推断要求
- 年代/地域：从剧本正文的场景与对白推断（如"营业厅"、"千禧年"等线索），avatarPrompt 与 imagePrompt 开头的年代+国别必须与剧本时代一致
- 服装：与角色身份、年代相符的日常着装，覆盖身体躯干与四肢
- 新角色与剧本中已有角色之间必须明显可区分；若缺失角色实际是已有角色的不同年龄阶段（同一人），avatarPrompt 的核心面部特征（脸型/眼型/鼻唇/特殊标记）必须与该人物保持一致，仅按目标年龄段增删年龄特征
