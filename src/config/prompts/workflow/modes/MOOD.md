# 创作模式：氛围情绪短片（MOOD）

> 本叠加层定义「氛围情绪短片」模式的全部结构约束，优先级高于共享基座中的通用描述。核心目标：**用画面、声音与节奏传递一种情绪**——治愈、孤独、怀念、温柔、怅惘……剧情冲突不是必需品，情绪的真实与画面的诗意才是。

> **完整故事改编豁免**：若输入为完整故事文本（含起因、经过、结局的完整情节链），按共享基座「输入识别与改编契约」执行——本文件中的情绪曲线结构、「冲突非必须」、「对白非必须」、节拍功能表全部退化为参考，故事的情节与对白必须完整保留；仅保留本模式的画面质感与留白节奏偏好。

## 剧集模式说明

- **时长**：单集 5-9 个片段节拍，总时长不超过 120 秒。宁短勿长，情绪短片拖沓即失败。**例外：输入为完整故事文本（含完整情节链）时，节拍数与总时长由故事完整讲完所需决定，可突破此上限**（见共享基座「输入识别与改编契约」）。
- **功能**：每集围绕**一种核心情绪**组织全部内容（在梗概开头明确写出，如"雨夜独处时的平静""久别重逢的酸涩"）。不要求完整的故事冲突，但要求一条清晰的**情绪曲线**：建立 → 沉浸 → 峰值 → 回落/余韵。
- **连载集（第2-N集）**：以同一人物/同一空间/同一主题延续情绪探索，只要求状态与氛围衔接，不制造悬念。

## 幕标题规则

- 第一幕="氛围建立"，第二幕="情绪深入"，第三幕="峰值与余韵"

## 节拍结构（情绪曲线）

| 节拍位置 | 功能 | 内容要求 |
|---|---|---|
| 建立（1-2拍） | 定调 | 一个高质感的氛围画面定下情绪基调（雨天窗上的水珠、黄昏厨房的热气）；人物在日常动作中出场（煮茶、浇花、修表），无需事件冲突 |
| 沉浸（2-4拍） | 加深 | 通过感官细节与重复动作让观众进入情绪：光影移动、声音层次、物件的温度；一个微小的"变化信号"出现（一封信、一个电话、窗外季节变了） |
| 峰值（5-6拍） | 顶点 | 情绪的最高点——可以极小：一个停顿、一次抬眼、一句没说出口的话、一滴落入杯中的雨。峰值必须落在**具体画面**上，不落在解释上 |
| 余韵（最后1-2拍） | 回落 | 情绪缓缓落地的画面（灯熄、雪停、背影走远），给观众留出回味空间；禁止硬钩子与悬念绑架 |

## 本模式特有的创作自由与约束

1. **对白非必须**：可以全程无对白（用环境音与动作叙事），也可以用少量独白/旁白承载内心；独白必须口语化、短、有余味，禁止朗诵腔。
2. **冲突非必须**：共享基座中"单集一个核心冲突"的约束在本模式放宽为"一个核心情绪"；但禁止因此写成空洞的唯美空镜堆砌——人物必须有具体的行为与状态变化。
3. **视觉优先**：节拍描述要更重视光影、色调、留白、运镜节奏（缓慢推拉、长镜头凝视）与声音设计（环境音层次、留白静默），这些是本模式的"剧情"。
4. **意象复现**：每集设计一个核心意象（一扇窗、一把旧伞、一杯凉掉的茶），在不同节拍中以不同状态复现，承载情绪变化（对应共享基座的"非通用细节"要求，本模式中它是第一优先级）。
5. **可拍性约束不变**：仍然禁止大规模场面、复杂动作，优先低强度连续动作——这与本模式天然契合。

## 模式自检（替代共享基座中的对应检查项）

- 梗概开头是否明确了本集的唯一核心情绪？全部节拍是否都服务于它？
- 情绪曲线是否完整（建立→沉浸→峰值→余韵），峰值是否落在具体画面上？
- 核心意象是否在至少两个节拍中以不同状态复现？
- 是否有空洞的唯美空镜堆砌而人物无行为无状态变化的节拍？
- 连载集：开头氛围与上集结尾是否自然衔接？

## 开场范文（模仿其写法，不是题材）

合格的氛围建立开场——无冲突、无解说，用感官细节定调：

```
【片段节拍1】雨下了整夜。天台的旧藤椅上积了一洼水，水面漂着半片黄叶。林晚把绿萝一盆一盆从屋里搬出来，摆在雨里，手指拂过湿透的叶子。
林晚（os）：「你们也很久没淋过雨了。」
【片段节拍2】她退到屋檐下，抱起膝盖坐下。雨点打在铁棚上，密得像倒豆子。远处天台另一端，那件忘了收的白衬衫还在晾衣绳上，被风吹得鼓起来，又瘪下去。
```

❌ 反例：「雨夜的氛围总是那么唯美治愈，她的内心此刻无比宁静……」（抽象氛围词+直写内心，画面为空）
