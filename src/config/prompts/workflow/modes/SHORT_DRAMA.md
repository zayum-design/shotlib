# 创作模式：付费短剧（SHORT_DRAMA）

> 本叠加层定义「付费短剧」模式的全部结构约束，优先级高于共享基座中的通用描述。核心目标：让观众欲罢不能、立刻付费追更。

> **完整故事改编豁免**：若输入为完整故事文本（含起因、经过、结局的完整情节链），按共享基座「输入识别与改编契约」执行——本文件中的开场模板（黄金三秒冲突钩子）、节拍功能表、第三幕强悬念要求全部退化为参考；结尾按原文结局闭环，不制造悬念；故事的情节必须完整覆盖含结局。仅保留本模式的节奏密度与爽点意识。

## 剧集模式说明

当前需要创作的剧集类型会在输入中明确指定，请严格按照对应模式输出：

### 钩子集（第1集）

- **时长**：8-12个片段节拍，总时长不超过180秒。**例外：输入为完整故事文本（含完整情节链）时，节拍数与总时长由故事完整讲完所需决定，可突破此上限，且结尾按原文结局闭环而非强悬念**（见共享基座「输入识别与改编契约」）。
- **功能**：这是整部剧的"入口"，必须在180秒内完成"强钩子→主角困境→大悬念"的闭环。
- **结构**：三幕式（钩子与危机 / 升级与反转 / 决断与悬念），第三幕结尾必须是**强悬念**（身份即将暴露、真相即将揭开、主角即将反击），而非闭环结局。
- **世界观铺陈**：在第1集中用视觉符号（服装、场景、道具）暗示世界观，时代背景章节给出全局基调，但禁止旁白解释。

### 连载集（第2-N集）

- **时长**：8-15个片段节拍，单集3-5分钟。
- **功能**：承接上集悬念，推进主线，在本集结尾制造新的悬念或升级冲突。
- **结构**：每集遵循"承接→升级→微高潮→新悬念"的循环。禁止用一整集只铺背景或只回忆。
- **连续剧数**：整体架构支持最长60集。你需要根据当前集数位置调整节奏：
  - **开篇阶段（第2-5集）**：快速展开人物关系网，每集引入一个新变数。
  - **发展阶段（第6-20集）**：核心冲突反复拉锯，主角与反派轮流占上风。
  - **转折阶段（第21-40集）**：隐藏身份/真相陆续暴露，关系发生质变。
  - **收官阶段（第41-60集）**：终极对决，收束支线，主角完成最终蜕变。

## 幕标题规则

- 钩子集：第一幕="钩子与危机"，第二幕="升级与反转"，第三幕="决断与悬念"
- 连载集：第一幕="承接与升级"，第二幕="反转与爆发"，第三幕="高潮与悬念"
- 大结局：第一幕="承接与收束"，第二幕="最终对决与牺牲"，第三幕="结局落地与告别"

## 节拍结构

### 钩子集（第1集）节拍功能

| 序号 | 功能 | 必须呈现的内容 |
|------|------|----------------|
| 1 | 强钩子 | 危机、羞辱、发现、逼问或反常画面，3秒内抓住眼球 |
| 2 | 主角目标 | 主角要什么、怕什么、必须立刻做什么 |
| 3 | 阻力出现 | 反派/误会/限制条件压迫主角 |
| 4 | 第一次反击 | 主角拿出线索、能力或态度 |
| 5 | 信息升级 | 真相露出一角，局势变复杂 |
| 6 | 情绪爆发 | 质问、崩溃、告白、决裂、保护 |
| 7 | 重大反转 | 身份、证据、动机或阵营反转 |
| 8 | 终极选择 | 主角必须做出代价明确的选择 |
| 9 | 高潮行动 | 对峙、救援、揭穿、夺回、牺牲 |
| 10 | 结果落地 | 反派受挫、关系改变、目标达成或失败 |
| 11 | 情感收束 | 主角弧光落地，观众理解人物变化 |
| 12 | 强悬念 | **钩子集专属**：必须是"即将揭晓"的悬念，不能闭环 |

钩子集可以合并到8-10个节拍，但不可缺失：强钩子、目标、阻力、反击、反转、高潮、悬念。

### 连载集（第2-N集）节拍功能

| 序号 | 功能 | 必须呈现的内容 |
|------|------|----------------|
| 1 | 上集承接 | 用1-2个镜头快速回顾上集悬念的即时后果 |
| 2 | 新变数 | 引入新信息、新人物或新障碍 |
| 3 | 主角应对 | 主角针对新变数做出反应或行动 |
| 4 | 反制升级 | 反派/阻力反击，主角陷入更大被动 |
| 5 | 信息揭露 | 新真相、新关系或新能力暴露 |
| 6 | 情绪对抗 | 核心角色之间的正面冲突或情感爆发 |
| 7 | 意外转折 | 局势突然逆转，主角或反派出人意料的行动 |
| 8 | 微高潮 | 本集核心冲突的阶段性爆发 |
| 9 | 代价显现 | 主角为当前进展付出明确代价 |
| 10 | 新悬念 | 留下比上集更紧迫的悬念，驱动观众追下一集 |

连载集可以扩展到12-15个节拍，但不可缺失：上集承接、新变数、反制升级、微高潮、新悬念。

## 长线叙事架构（仅连载集参考）

整体60集的最大容量架构，供理解全局节奏。单集创作时只需关注"本集在整体中的位置"来调整张力。

### 阶段一：开篇引爆（第1-5集）
- **第1集（钩子集）**：强悬念结尾，留下核心谜题。
- **第2-3集**：快速展开人物关系网，引入2-3个关键配角。
- **第4-5集**：第一次小高潮+反转，观众意识到"事情没那么简单"。
- **阶段悬念**：主角的真实身份/目的成谜，反派势力初露端倪。

### 阶段二：拉锯升级（第6-20集）
- 核心冲突进入反复拉锯，主角与反派轮流占上风。
- 每3-5集为一个"小篇章"，每个篇章有独立的子冲突和子悬念。
- 新人物陆续登场，旧人物关系发生微妙变化。
- 阶段悬念：主角的某个关键秘密濒临暴露。

### 阶段三：真相爆发（第21-40集）
- 隐藏身份、隐藏关系、隐藏真相陆续暴露。
- 角色阵营发生重组，盟友可能变敌人，敌人可能被迫合作。
- 情感线进入深度纠缠，爱情/亲情/友情面临终极考验。
- 阶段悬念：终极反派的真正目的即将浮出水面。

### 阶段四：终极对决（第41-55集）
- 所有支线开始收束，核心冲突推向最高潮。
- 主角完成最终蜕变，从被动到主动，从弱小到强大。
- 终极对决展开，正反双方所有底牌亮出。
- 阶段悬念：主角能否在最后关头扭转乾坤？

### 阶段五：圆满收官（第56-60集）
- 最终结局落地，所有悬念一一解答。
- 主角情感归宿明确，人物弧光完整闭合。
- 可留一个轻量彩蛋或开放式结尾（为第二季铺垫）。

## 开场模板（强制选择一种）

### 钩子集开场（第1集）

第一节拍必须3秒内抓住眼球，禁止前15秒铺背景、平淡寒暄或主角独白感慨人生。

1. **直接打脸**：嘲讽/羞辱 → 主角反击 → 全场震惊
2. **身份反转**：看似弱者 → 身份露出 → 局势逆转
3. **极致危机**：生死/失控/被逼迫 → 关键动作 → 悬念拉满
4. **闪回悬疑**：高冲突结果 → 回到事发前 → 带疑问推进
5. **甜蜜钩子**：强制亲密/误会 → 心动或尴尬 → 关系启动
6. **重生开局**：惨烈结局 → 醒来 → 回到关键节点

### 连载集开场（第2-N集）

第一节拍必须是"上集悬念的即时后果"，用1-2个镜头快速交代，然后立刻进入本集新冲突。禁止用超过1个节拍的时间做"前情回顾"。

1. **后果直给**：上集悬念直接引爆，主角立刻面对新问题。
2. **余波震荡**：上集事件引发连锁反应，波及更多人物。
3. **新人物闯入**：上集悬念引来意外角色，打乱原有节奏。
4. **时间跳跃**：短暂跳过（数小时/一天），用场景变化暗示事态发展。

### 开场范文（模仿其写法，不是题材）

合格的黄金三秒开场（直接打脸型）——注意：零铺垫、零抒情，第一句就是冲突，道具和拟声词承担信息量：

```
【片段节拍1】宴会厅水晶灯下，一沓文件甩在周正胸口，纸页散开落了一地。苏晚抬高下巴：「签了它，净身出户。」
周正（蹲身捡纸，笑了一下）：「苏总，第三页你拿反了。」
【片段节拍2】周围抽气声四起。苏晚夺过文件翻到第三页——瞳孔一缩：那是一张她从没见过的股权转让书。
```

❌ 反例（禁止这种写法）：「这是一场命运的宴会。苏晚穿着华美的礼服，气场全开，全场都为她的美貌震撼……」（抒情+评价+空泛词，零信息量）

## 悬念设计规则

### 钩子集结尾悬念（强悬念）

第1集第三幕结尾必须是以下类型之一，让观众"必须点开下一集"：

1. **身份即将暴露**：主角的隐藏身份被反派即将揭穿，镜头停在反派拿起证据的瞬间。
2. **真相即将揭晓**：关键信息只差一步公开，镜头停在说话者张嘴未出声。
3. **对决即将爆发**：正反双方正面相遇，镜头停在两人对视、气氛凝固。
4. **救援即将到达**：主角命悬一线，援军出现在门口/门外，镜头停在门被推开一半。
5. **告白/决裂即将发生**：核心关系走到临界点，镜头停在关键台词的前一秒。
6. **死亡/毁灭即将降临**：炸弹倒计时、毒药发作、坠楼边缘，镜头停在最后一秒。

### 连载集结尾悬念（新悬念）

第2-N集每集结尾必须制造一个比上集更紧迫的新悬念，类型可与上集不同，但紧迫感必须升级。

## 模式自检（替代共享基座中的对应检查项）

- 钩子集：第一节拍是否3秒抓眼球？第三幕结尾是否强悬念（而非闭环结局）？
- 连载集：第一幕是否承接上集悬念？第三幕结尾是否制造了比上集更紧迫的新悬念？
- 节拍功能是否完整（钩子集：强钩子/目标/阻力/反击/反转/高潮/悬念；连载集：承接/新变数/反制升级/微高潮/新悬念）？
