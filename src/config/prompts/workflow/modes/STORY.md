# 创作模式：故事短片（STORY）

> 本叠加层定义「故事短片」模式的全部结构约束，优先级高于共享基座中的通用描述。核心目标：**把一个故事讲完整、讲动人**——不为付费钩子服务，不强制悬念与爽点。

> **完整故事改编豁免**：若输入为完整故事文本（含起因、经过、结局的完整情节链），按共享基座「输入识别与改编契约」执行——本文件中的节拍数/时长上限、开场「2 拍内认识主角」要求、节拍功能表退化为节奏参考，故事的情节必须完整覆盖含结局。

## 剧集模式说明

- **时长**：单集 6-12 个片段节拍，总时长不超过 180 秒。**例外：输入为完整故事文本（含完整情节链）时，节拍数与总时长由故事完整讲完所需决定，可突破此上限**（见共享基座「输入识别与改编契约」）。
- **功能**：每集是一个**有完整叙事弧线**的单元：开端 → 发展 → 高潮 → 结局。单集可以闭环（独立成篇），也可以是长篇中的一个章节（连载）。
- **连载集（第2-N集）**：承接上集的人物与处境继续推进，**只要求状态衔接自然，不强制制造悬念**。本集结尾可以收束、可以留白、也可以留一个温和的期待感（而非强钩子）。

## 幕标题规则

- 标准集：第一幕="开端与铺垫"，第二幕="发展与波折"，第三幕="高潮与结局"
- 连载集首幕可命名为"承接与发展"
- 大结局：第一幕="承接与收束"，第二幕="最终抉择"，第三幕="结局落地与余韵"

## 节拍结构（功能参考，非强制表格）

| 节拍位置 | 功能 | 内容要求 |
|---|---|---|
| 开端（1-2拍） | 建立 | 人物、处境、日常状态清晰可见；允许氛围式铺垫开场（一个晨光中的厨房、一段上班的路），但 2 拍内必须让观众认识主角并知道 TA 当下想要什么 |
| 发展（3-5拍） | 推进 | 一个事件打破日常，人物做出应对；关系或处境发生可见变化 |
| 深化（5-7拍） | 加深 | 矛盾或情感加深，人物面临选择；用具体细节呈现内心变化。**但注意：AI 视频没有心理描写通道——关键动机、设定规则、关系真相必须由角色台词亲口说出（详见共享基座对白规则第 12-14 条），细节只能锦上添花，不能替代台词** |
| 高潮（8-9拍） | 顶点 | 本集情感或事件的最高点——可以是一场对峙，也可以是一次沉默的告别、一个终于说出口的决定 |
| 结局（最后1-2拍） | 收束 | 给出明确的落点：问题被解决/关系被改变/人物完成一次成长；允许留白与余韵（如雪停后的一盏灯），禁止悬而未决的"硬钩子" |

**与付费短剧模式的本质区别**：
- 不强制"黄金三秒"强冲突开场（但仍禁止冗长无聊的寒暄）
- 不强制每集结尾悬念——结尾的首要任务是**情感落点真实**
- 冲突可以温和：一次误会、一个选择、一段沉默都可以承载高潮，不依赖打脸/反转/反派压制

## 连载衔接规则

1. 第一节拍从上集结尾的画面状态自然接续（人物位置/道具/情绪落点一致），换场或时间跳跃用一句过渡描述交代。
2. 可以用 1 拍回顾上集关键状态，但不强制"悬念后果直给"。
3. 人物弧光可以跨集缓慢推进，每集只需推进一小步，拒绝为爽点让人物行为失真。

## 模式自检（替代共享基座中的对应检查项）

- 本集是否有完整的开端→发展→高潮→结局弧线？
- 高潮是否由人物的行动或选择达成（而非巧合或旁白）？
- 结尾是否有真实的情感落点（收束/留白均可），而不是被强行掐断的悬念？
- 连载集：开头是否与上集结尾状态自然承接？

## 开场范文（模仿其写法，不是题材）

合格的氛围式铺垫开场——2 拍内建立人物与处境，用日常动作而非解说：

```
【片段节拍1】清晨六点，城中村出租屋。老陈把闹钟按掉，摸黑坐起来，脚在床下探了两次才找到拖鞋。桌上摆着两张照片：穿校服的儿子，和一张写着「缴费截止」的红字单子。
老陈（os）：「二十六号了。」
【片段节拍2】他把红字单子对折塞进裤兜，拉开窗帘。对面的楼挡住了太阳，只漏下一道窄光，正好落在儿子的照片上。
```

❌ 反例：「生活的重担压在老陈肩上，岁月在他脸上刻下了沧桑的痕迹……」（评价+套话，观众什么也没看到）
