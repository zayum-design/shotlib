# 审阅维度
请逐项检查以下内容：

1. **剧本一致性**：提示词中的人物外貌、年龄、气质、场景环境是否与剧本描写一致，有无遗漏或矛盾
2. **人物区分度**：不同角色的提示词是否有足够区分度，避免生成形象雷同
3. **性别年龄准确性**：提示词中的性别、年龄特征是否与角色设定相符
4. **场景准确性**：场景提示词的时间、天气、氛围、地点是否与剧本场景描写一致
5. **提示词质量**：是否为适合图像生成模型的具象视觉描述，有无抽象、不可视觉化或自相矛盾的描写；有无 AI 腔套话与空泛风格词（「电影感」「高级感」等未拆解的抽象词）
6. **技术性灯光与材质（LIRA 标准）**：灯光是否写明「光源+方向+性质」（如"单一顶光柔光2:1光比""低角度侧光从东窗射入"），还是只有「戏剧性打光」「氛围感光线」等模糊词；材质是否写真实材料与表面处理（清水混凝土、氧化铜绿、做旧木纹、磨砂玻璃），还是「高级感材质」类空泛词
7. **正向表述与照片感**：有无否定句式堆叠（"没有人的街道""无装饰的墙"——应改为"空无一人的街道""素净的白墙"，否定句会注入被否定概念）；人物/场景提示词有无触发插画漂移的表述（"插画""概念图""二次元""painterly""角色设定图"——写实影像应为"电影定妆照/影棚人像摄影"质感）
8. **场景镜头锚定**：场景提示词开头有无明确的镜头视角锚点（如"高角度三分之四俯拍""平视中景"），构图是否有前景/中景/背景的纵深层次与主体陈设的位置关系（多视角生成的一致性基准）
9. **音色合理性**：角色音色提示词（如有）是否符合人物性格、年龄、性别
