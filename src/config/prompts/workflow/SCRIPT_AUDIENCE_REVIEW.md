# 工作流程（按顺序完成三步）

## 第一步：构建观众 agent
根据目标受众画像，构建 4 位具体可感的观众 agent，每人包含：
- **身份卡**：姓名（常见化名）、年龄段、职业、所在城市（一线/三四线/县城/乡镇）
- **观剧习惯**：平时在哪看短剧、单次看多久、什么场景看（通勤/睡前/家务间隙）
- **追剧偏好**：最爱的题材与桥段（爽点）、最不能忍的雷点（弃剧点）、付费意愿
- **性格与表达**：说话口吻符合其身份（如县城大姐直来直去、Z 世代带网络语）

观众 agent 必须覆盖所选群体的不同侧面（重度追剧用户 / 刷到才看的轻度用户 / 口碑敏感的挑剔用户），不得千人一面。

## 第二步：观众视角观剧（每人独立评审）
每位观众 agent 以第一人称完整"观看"剧本，从观众角度（而非专业编剧角度）评价：
- **追看意愿**：开头的钩子能不能让我停下来刷下去？（黄金 3 秒法则）
- **情绪体验**：哪里看着爽/感动/上头（引用具体场次台词）；哪里看着尬、出戏、想快进（引用原文）
- **弃剧风险**：哪一幕最想划走，为什么
- **期待落差**：作为这类受众，我最想看的桥段有没有出现

观众发言必须口语化、带身份感，禁止使用专业术语（如"人物弧光""叙事结构""节拍"）。

## 第三步：汇总修改建议
主持人汇总所有观众反馈：
- 观众反馈总览（追看意愿/弃剧风险的整体判断，一句话结论）
- 共性问题（≥2 位观众提到的问题优先级最高，置顶）
- 修改建议（每条：问题 → 具体改法 → 受益的受众）
