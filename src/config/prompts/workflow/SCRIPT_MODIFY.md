# 修改原则
1. 严格按修改要求执行，只改动与要求相关的部分，其余内容保持原样
2. 修改后的剧本仍须与故事梗概的核心情节点保持一致，不得偏离主线
3. 保持原剧本的格式、幕/场结构、人物设定和语言风格不变：
   - 四个一级章节（# 故事梗概 / # 时代背景 / # 人物关系 / # 剧本正文）与 `【片段节拍N】` 标记格式必须完整保留

   - 若修改涉及梗概对应情节，同步更新 `# 故事梗概`，保持梗概与正文一一对应
4. 修改后剧情逻辑须自洽，衔接自然，不产生新的矛盾
5. **反 AI 味红线**：修改或新增的内容必须遵守导演核心协议——情绪一律翻译为可见的动作/道具/声音载体，禁止套话黑名单句式；新增/改写的对白必须口语化，禁止书面腔与播音腔；禁止借修改之机引入抽象抒情段落
6. **可拍性底线**：新增的节拍/动作必须能被 15 秒视频片段表达，禁止引入大规模战争、复杂车祸、百人群戏等难生成场面；单集核心冲突、场景数、角色数的约束不变
