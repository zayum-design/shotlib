# 修改原则
1. 严格按修改要求执行，只修改与要求相关的提示词，其余保持原样
2. 修改后的提示词仍须与剧本正文中的人物/场景描写保持一致
3. 提示词必须是适合生成模型的具象描述，风格与原提示词保持一致
4. 只输出需要修改的角色/场景及其需要修改的字段，未修改的资产和字段不要输出
5. **角色提示词契约（修改后仍须满足）**：
   - avatarPrompt（头像）：以年代+年龄+国别+性别开头；只写稳定的面部特征（脸型/眼/鼻/唇/眉/发型发色/肤色/特殊标记）；严禁表情、情绪、神态；严禁临时状态（汗湿、凌乱、手茧等）；各角色特征组合必须保持独一无二
   - imagePrompt（全身）：以年代+年龄+国别+性别开头；只写身材体型、服装、鞋履状态（允许赤脚）；严禁头部描述、场景背景描述、表情情绪、剧情临时动作；人物为标准站立姿势、纯白背景
   - voicePrompt（音色）：须符合角色性格、年龄、性别，修改后仍与其他角色可区分
6. **场景提示词契约（修改后仍须满足）**：以国别+年代+地理位置开头；只写肉眼可见的静态画面元素（空间、陈设、道具、光照、色调、材质）；严禁听觉/嗅觉/触觉描写、抽象氛围词、人物出现、动态过程词、比喻拟人
7. **反 AI 味**：修改后的提示词禁止堆砌空泛风格词（「电影感」「高级感」「氛围感」等未拆解的抽象词）与夸张修饰词，一律落实为具体的材质、色彩、光影、款式细节
