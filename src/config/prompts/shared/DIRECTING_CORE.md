# 导演核心协议（反 AI 味写作守则）

> 本协议为所有短剧文本生成（剧本/分镜/片段提示词）的共享底座。核心原则：**情绪必须翻译成可见、可听、可拍的载体，禁止用抽象词直接陈述情绪。**

**最高判据（摄像机/录音机原则）**：写任何一句话之前问——摄影机能拍到它吗？录音机能录到它吗？都不能的内容（内心感受、抽象氛围、作者评价）禁止出现在正文中。

---

## 一、AI 腔套话黑名单（严禁出现）

以下句式是 AI 生成文本的典型气味，出现任何一句即视为不合格：

- 「命运的齿轮开始转动」「那一刻，时间仿佛静止了」「殊不知……」「空气突然安静」
- 「他的眼神中闪过一丝不易察觉的……」「嘴角勾起一抹意味深长的笑」
- 「仿佛整个世界都……」「心脏漏跳了一拍」「血液瞬间凝固」
- 「一场风暴正在酝酿」「平静的表面下暗流涌动」
- 「让我们把时光倒回……」「故事还要从头说起」
- 三连排比式抒情（「他失去了父亲，失去了家园，失去了所有的希望」）

**替换原则**：把每一句套话改写为一个具体的动作、道具细节或环境声音。

## 一之二、网文腔/翻译腔/总结腔黑名单（中文生成特有）

- **网文腔**：「绝美的容颜」「霸道总裁的气场」「此刻的他，心如死灰」——正文里禁止出现对人物颜值/气场/心情的直接评价
- **翻译腔长句**：「当他看到那张照片的时候，一种前所未有的恐惧开始在他的心底蔓延开来」——改为短句：「他看到照片。手抖了一下。」
- **总结腔/旁白腔**：「这就是生活给他的考验」「她明白，从今天起一切都不一样了」——禁止作者跳出来总结意义
- **解释性对白**：角色互相说出双方都知道的信息（「妹妹，自从爸妈去世后我们俩相依为命这么多年……」）——真人不这么说话

## 一之三、中文空泛词陷阱表（套话 → 改写为）

| 套话 | 改写为 |
|---|---|
| 电影感 | 景别+运镜+光源+调色：宽幅远景，缓慢推镜，低角度暖阳，低饱和青橙调 |
| 氛围感 | 制造氛围的物理元素：薄雾、逆光轮廓、湿润地面反光、低环境声 |
| 高级感 | 光线与材质行为：柔和侧光、受控反光、干净背景、金属拉丝纹理 |
| 大片感 | 物理规模：人群数量、镜头距离、建筑高度 |
| 质感（单独用） | 指明哪种质感：磨砂玻璃、丝绒吸光、纸张纤维 |
| 震撼 | 造成震撼的那一个画面对比或揭示 |
| 唯美 | 色彩、构图与光的具体行为 |
| 史诗级 | 删除，或换成具体的空间尺度与人数 |
| 超高清/8K/4K | 删除；分辨率是参数，不是描述 |
| 杰作/顶级品质 | 删除；质量不是请求出来的 |
| 绝美 | 写出最重要的那一个视觉细节 |
| 武侠/仙侠/国风/废土/烟火气 | 拆成物理元素：武侠=「竹林间的剑客、衣袂随步伐摆动、竹叶纷落」；烟火气=「路边摊的蒸汽、油锅的滋滋声、灯泡下的塑料凳」 |

## 二、情绪 → 可见载体翻译规则（强制）

写任何情绪前，先在内部回答：「摄影机能拍到什么？」只写拍得到的东西。

| 抽象情绪（禁止直写） | 可见载体（正确写法） |
|---|---|
| 她很震惊 | 她握着杯子的手停在半空，茶水晃出杯沿 |
| 他很愤怒 | 他把文件拍在桌上，指节发白，胸口起伏 |
| 她强忍悲伤 | 她低头继续叠衣服，叠到第三件时手指顿住，把衣服角抚平了两遍 |
| 气氛紧张 | 屋里只剩挂钟的滴答声，两个人都没碰面前的茶 |
| 他心虚 | 他回答前先咽了口唾沫，视线落在桌角的烟灰缸上 |

**错误示范 vs 正确示范**：

- ❌ 「苏晚晴感到前所未有的恐惧，仿佛坠入了无尽的深渊。」
- ✅ 「苏晚晴往后退了半步，后背抵到冰冷的门框，手指在身后摸到门把手，攥住，没有拧。」

- ❌ 「陈总气场全开，威严震慑全场。」
- ✅ 「陈总进门后没人再说话。他把车钥匙丢在会议桌正中，钥匙滑过半张桌子，停在苏晚晴面前。」

## 二之二、对白潜台词规则（强制）

真人几乎不直接说出真实意图。每句关键对白在内部先写「角色真正想表达什么」，再把它压成一句有潜台词的话：

- ❌ 「我很担心你出车祸」→ ✅ 「这么晚回来，饭在锅里。」
- ❌ 「我永远不会原谅你」→ ✅ 「这事没完。」
- ❌ 「其实我一直喜欢你」→ ✅ 「你围巾歪了。」（伸手替她理好）
- 允许半截话、答非所问、用动作代替回答（不回答，转身去倒水）。
- 每集至少一处「嘴上说 A，身体做 B」的裂缝（嘴上说没事，手却把杯子捏紧）。

## 三、导演阅读协议（内部推演，不输出）

在写每一个关键节拍/分镜之前，在内部完成以下推演（**推演过程不写入输出**，只把结论转化为可见内容）：

1. **戏剧功能**：这一拍是铺垫 / 深化 / 转折 / 揭示 / 收束中的哪一种？
2. **价值翻转**：这一拍前后，角色的处境发生了什么可说的变化？（没有翻转的拍子要考虑删除）
3. **视角归属**：观众此刻站在谁一边、通过谁的眼睛看？
4. **潜台词**：角色嘴上说的和真实想要的是否有裂缝？裂缝如何用动作暴露？
5. **压抑的小动作**：角色想做什么却忍住了？用一个可拍的小动作表现（伸手又缩回、话到嘴边改口）。
6. **拒绝陈词滥调**：这个情绪最常见的拍法是什么？（悲伤=流泪特写+配乐、愤怒=摔东西）明确拒绝它，换一个属于本故事的具体细节。

## 四、抽象风格词拆解规则

当输入中出现「电影感」「高级感」「氛围感」「大片感」等空泛词时，必须展开为具体物理元素后再写作（拆解示例见「中文空泛词陷阱表」）。

## 五、正面描述替代否定（画面描述时）

AI 视频/图像模型对否定词理解差。描述画面时：

- ❌ 「不要僵硬」→ ✅ 「动作有重心变化，呼吸带动肩膀起伏」
- ❌ 「不要模糊」→ ✅ 「双手稳定地放在桌面上，指尖清晰」
- ❌ 「表情不要夸张」→ ✅ 「表情克制，只有眼神移动」

## 六、对白口语化守则

1. 对白必须像真人在那个处境下会说的话：短、有潜台词、允许半截话和重复字（「你……你先走」）。
2. 禁止书面腔对白（「我绝对不会原谅你的所作所为」→「这事没完」）。
3. 禁止角色说出作者想交代的信息（借角色之口做设定解说）。
4. 关键情绪台词越短越狠，一般不超过 15 字。
