# 镜头语言合同（SHOT LANGUAGE）

> 本分镜合同为所有分镜/片段提示词的共享规范。核心原则：**一个镜头 = 一个主体动作 + 一个主要运镜 + 一个明确的起始帧与结束帧状态。**

---

## 一、字段枚举（与系统前后端词表严格对齐，禁止自造值）

### shotType（景别）
| 值 | 中文 | 叙事用途 |
|---|---|---|
| extreme_close_up | 大特写 | 微表情、瞳孔、手部细节、关键道具 |
| close_up | 近景 | 情绪转折、关键对白 |
| medium_close_up | 中近景 | 对白、对峙 |
| medium | 中景 | 人物动作、双人关系 |
| medium_long | 中远景 | 人物与环境关系 |
| long | 远景 | 环境建立、孤独感、段落开场 |
| extreme_long | 极远景 | 大全景、时代/地域氛围 |

### cameraMovements（运镜，单镜只选 1 种）
static(固定) / push_in(推) / pull_out(拉) / pan_left(左摇) / pan_right(右摇) / tilt_up(上摇) / tilt_down(下摇) / track(跟) / dolly(移) / crane_up(升) / crane_down(降) / rotate(旋转) / zoom(变焦) / handheld(手持) / through_legs(双腿叉开) / over_waist(过腰) / over_shoulder(过肩) / reverse_swoop(反向包抄) / god_view(上帝视角) / bay_orbit(迈克尔贝环绕) / rack_focus(虚实焦切换)

### cameraAngle（角度）
eye_level(平视) / low_angle(仰视) / high_angle(俯视) / bird_eye(鸟瞰) / worm_eye(虫视) / dutch_angle(倾斜)

### lighting（灯光）
natural(自然光) / soft(柔光) / hard(硬光) / rembrandt(伦勃朗光) / backlight(逆光) / rim(轮廓光) / practical(实景光) / cinematic(电影光)

### mood（氛围）
bright(明亮) / dark(昏暗) / warm(暖色调) / cool(冷色调) / moody(忧郁) / ethereal(空灵) / noir(黑色电影) / vibrant(活泼)

## 二、单镜头撰写公式

每个分镜 prompt 按以下顺序组织信息：

```
景别+角度开头 → 场景标记（首次出现）→ 主体+一个主动作 → 一个主要运镜 → 起始帧状态 → 结束帧状态（本镜结束时的画面落点）→ 具体光源 → 画面约束后缀
```

硬性约束：
1. **单镜单运镜**：禁止推拉摇移叠加；推镜后必须揭示推镜前看不清的细节，无信息增量的推镜禁止。
2. **单镜单动作**：一个镜头只承载一个主体动作（如「她撕毁照片」），不要把「撕照片→扔向对方面部→转身离开」塞进一个镜头，应拆为 2-3 个镜头。
3. **结束帧必须明确**：写清本镜最后一帧的画面状态（「结束于照片碎片落在桌面上」），这是与下一镜头衔接的锚点。
4. **运镜与情绪匹配**：紧张/追逐→快速横移/跟拍/手持；平静/沉思→缓慢推镜/固定；权力压制→低角度固定。
5. **运镜必须有理由**：镜头运动跟随主体动作或揭示新信息，禁止无目的炫技运镜（360° 旋转、希区柯克变焦仅在揭示重大反转时使用一次）。

### 运镜剧情自动分配表（根据剧情需要自动选择，禁止全片固定/推镜打头）

分解片段时为每个分镜从表中按剧情语义自动分配运镜：先看「叙事触发场景」列，命中即用对应运镜；一集内同一特殊运镜（非基础运镜）最多出现 2 次，避免炫技堆砌。

| 运镜 | 叙事触发场景 | 画面效果要求 |
|---|---|---|
| static 固定 | 对峙、压迫、平静陈述、关键对白 | 画面稳定，靠表演与构图承载张力 |
| push_in 推 | 情绪升级、发现细节、内心转折 | 推镜后必须揭示推前看不清的细节 |
| pull_out 拉 | 揭示环境、孤独感、段落收束 | 拉出后环境与人物关系一眼看清 |
| pan/tilt 摇 | 扫过现场、跟随视线、空间建立 | 摇镜起止点都有明确信息 |
| track 跟 / dolly 移 | 追逐、行走对话、穿越空间 | 跟随主体移动，背景持续变化 |
| crane_up/down 升降 | 大场面开场/收尾、命运感转折 | 升降带来格局变化 |
| handheld 手持 | 混乱、恐慌、紧张搜寻 | 轻微晃动，禁止过度抖动 |
| through_legs 双腿叉开 | 强势人物登场/走过、压迫性对峙、从低位仰视权力关系 | 低机位从叉开的双腿之间穿过拍摄，前景腿部形成天然画框，强烈透视纵深 |
| over_waist 过腰 | 隔物对话、谈判、餐桌/吧台对峙 | 镜头越过一人腰部拍摄对面主体，腰部以下作前景虚化画框 |
| over_shoulder 过肩 | 双人对话、对峙、窥视视角 | 越过一人肩部拍摄另一方，肩线构图，代入旁观视角 |
| reverse_swoop 反向包抄 | 揭示反转、从一方绕到另一方展现对立、跟踪者现身 | 镜头弧形绕行至主体另一侧，揭示其背后/对面的信息，一集最多 2 次 |
| god_view 上帝视角 | 段落开场俯瞰全场、人物如棋子的命运感、密谋/围捕布局 | 垂直正上方 90° 俯瞰，人物与空间关系一眼看清 |
| bay_orbit 迈克尔贝环绕 | 动作/爆炸高潮、英雄时刻、激烈冲突顶点 | 低机位广角高速环绕主体半周到一周，背景拉伸变形，一集最多 1 次 |
| rack_focus 虚实焦切换 | 信息揭示（前景虚化→后景关键物/人清晰）、关系转变、意识到被注视 | 焦点由前景主体平滑转移到后景主体（或反向），完成虚实转换 |

### 运镜时间轴编排（与第四节五段时间轴严格对应，每个 shot 先定位时间段再选运镜）

| 时间段 | 段落职责 | 首选运镜 | 备选运镜 | 编排要点 |
|---|---|---|---|---|
| 0-3s 建立 | 场景/人物/处境一眼看清 | pull_out / pan / god_view / crane_down / static | dolly / tilt_down | 开场优先给空间关系与人物位置，上帝视角/升降仅在此段或段落级开场使用 |
| 3-6s 引入 | 主体动作开始，矛盾双方就位 | track / over_shoulder / dolly | over_waist / tilt_up | 带入人物关系：对话→过肩，隔物对峙→过腰，行走入场→跟随/横移 |
| 6-9s 发展 | 冲突升级，信息揭露一角 | push_in / rack_focus / tilt_down | reverse_swoop / over_waist | 信息开始出现：推镜揭示细节，虚实焦转移视线到关键物/人 |
| 9-12s 高潮 | 情绪或动作最高点 | bay_orbit / handheld / through_legs / push_in | tilt_up / zoom | 全段能量顶点才允许炫技运镜（迈克尔贝环绕/双腿叉开），文戏高潮用推镜或手持 |
| 12-15s 落点 | 收束/延续锚点/悬念定格 | static / pull_out / crane_up | rack_focus / crane_down | 安静落地：固定定格、拉出交代结果、升起抽离；落点镜不再引入新运镜花样 |

**编排顺序示范（4 镜片段）**：`crane_down（建立）→ over_shoulder（引入对话）→ rack_focus（发展揭示）→ static（落点定格留钩）`。
**反例（禁止）**：`static → push_in → static → push_in`（全片单调，配额违规）。

### 运镜逐条使用详解（何时用 / 何时不用 / prompt 写法）

**基础运镜**
- **static 固定**：用于关键对白、对峙僵持、平静陈述、权力压制凝视（配 low_angle）、悬念定格落点。不用于情绪升级段与需要展示空间关系的镜头。写法「中景固定」「近景固定，平视视角」。
- **push_in 推**：用于情绪升级、发现细节、内心转折；推镜后画面必须出现推前看不清的新信息。禁止无信息增量推镜、禁止连续两镜都推。写法「缓慢推近」「推近至面部特写」。
- **pull_out 拉**：用于揭示环境与人物关系、孤独感渲染、段落收束、从细节拉回全局。不用于需要聚焦情绪的镜头。写法「缓缓拉远」「镜头后拉 reveal 全场」。
- **pan_left / pan_right 摇**：用于扫过现场多个主体、跟随人物视线、空间建立、同镜内「A 看→B 反应」衔接。不用于单一主体情绪镜头。写法「镜头向左横摇」「随她视线摇向门口」。
- **tilt_up 上摇**：用于从脚部/细节升起揭示全貌、跟随人物站起、权力登场（配 low_angle）的崇高感。写法「镜头沿她起身缓缓上移」。
- **tilt_down 下摇**：用于从面部落到手部关键动作、从全貌落到细节、高位俯视下行的压迫感。写法「镜头下移落到她攥紧的手上」。
- **track 跟**：用于追逐、行走对话、跟随主体穿越空间；主体静止时禁用。写法「跟随她快步穿过走廊」。
- **dolly 移**：用于平行横移展现场景层次、侧跟行走、从遮挡物后横移揭示主体。写法「镜头横移，前景花瓶虚化划过」。
- **crane_up 升**：用于段落开场从人物拉高俯瞰全场、场面揭示、收尾时抽离产生命运感。写法「镜头向上升起， reveal 整条街」。
- **crane_down 降**：用于从大环境落到人物身上、进入场景的开场、收尾沉降。写法「镜头从楼顶缓缓降下落到她肩头」。
- **rotate 旋转**：仅用于眩晕、失控、重大心理反转，全剧最多 1 次。常规叙事禁用。写法「镜头随她眩晕缓缓旋转」。
- **zoom 变焦**：用于快速变焦模拟突然发现或惊吓（不改变机位只改变焦距）；希区柯克式变焦仅限重大反转，全剧最多 1 次。写法「急速变焦推近她瞳孔」。
- **handheld 手持**：用于混乱、恐慌、紧张搜寻、争吵升级；轻微晃动，禁止过度抖动；平静段落禁用。写法「手持跟拍，画面轻微晃动」。

**特殊运镜（每集限频，只能在时间轴对应段落使用）**
- **through_legs 双腿叉开**（≤2 次/集，仅限引入段或高潮段）：强势人物登场/走近、权力压制低位仰视、从叉开的双腿间看对面事件；前景腿部形成天然画框。写法「低机位从她叉开的双腿之间穿过拍摄」。文戏日常对话禁用。
- **over_waist 过腰**（≤2 次/集，引入段/发展段）：隔桌谈判、餐桌/吧台对峙、前景人物腰部以下虚化框住对面主体。写法「镜头越过她腰部拍摄对面的他」。单人镜头禁用。
- **over_shoulder 过肩**（≤3 次/集，引入段首选）：双人对话、对峙、窥视视角；肩线作前景构图，代入旁观视角。写法「越过周正的肩膀拍摄林晚」。单人独白禁用。
- **reverse_swoop 反向包抄**（≤2 次/集，发展段/高潮段）：揭示反转、镜头从一方弧形绕行至另一方展现对立全貌、跟踪者/第三方现身。写法「镜头绕到她身后 reveal 门口的人」。无反转信息的场景禁用。
- **god_view 上帝视角**（≤2 次/集，建立段）：垂直正上方 90° 俯瞰，开场俯瞰全场布局、密谋/围捕/棋盘点位的命运感。写法「垂直俯拍，人物如棋子在棋盘上」。情绪特写场景禁用。
- **bay_orbit 迈克尔贝环绕**（≤1 次/集且全剧高光时刻，仅高潮段）：动作/爆炸/激烈冲突顶点、英雄时刻；低机位广角高速环绕主体半周到一周，背景拉伸变形。写法「低机位高速环绕她一周，广角背景拉伸」。文戏禁用，整剧 ≤2 次。
- **rack_focus 虚实焦切换**（≤3 次/集，发展段/落点段）：信息揭示（前景虚化→后景关键物/人清晰）、关系转变、意识到被注视的时刻；焦点平滑转移完成虚实转换，机位不动。写法「焦点由前景虚化的手机缓缓落在她脸上」。需移动机位时禁用（那是推镜）。

## 三、景别与叙事匹配

| 叙事功能 | 推荐景别 | 禁止景别 |
|---|---|---|
| 微表情/震惊/恐惧 | 大特写/近景 | 中景/全景 |
| 情绪转折/关键对白 | 中近景/近景 | 远景 |
| 空间关系/环境建立 | 远景/中远景 | 特写 |
| 动作细节/手部操作 | 大特写/近景 | 中景 |
| 对峙/冲突张力 | 中景/中近景 | 远景 |

### 关键动作特写（强制）

剧本中的高信息量动作瞬间——受伤流血、攥紧拳头、刀刃/凶器出鞘、信物掉落或被攥皱、手指颤抖、关键道具被操作（按键、撕毁、递出、按进伤口）——**必须**有对应的近景/大特写镜头（`close_up / extreme_close_up`），以该细节为画面主体写清视觉状态（如「腹部伤口的鲜血顺着指缝渗出，一滴、两滴砸在地板上」）。时长或镜头数预算不足时，把该瞬间所在镜头的景别直接改为特写，而非放弃。禁止把关键动作细节压在中远景里一带而过。

## 四、15 秒五段时间轴（单片段节奏模板）

一个 15 秒片段按以下时间轴分配叙事职责，每个 shot 必须知道自己服务于哪一段：

| 时间段 | 职责 | 内容要求 |
|---|---|---|
| 0-3s | 建立 | 场景/人物/处境一眼看清，3 秒内出现冲突信号或反常画面 |
| 3-6s | 引入 | 主体动作开始，矛盾双方就位 |
| 6-9s | 发展 | 冲突升级，信息揭露一角 |
| 9-12s | 高潮 | 本片段的情绪或动作最高点 |
| 12-15s | 落点/留钩 | 给出改变后的状态，或停在悬念瞬间（未完成的动作、未说出口的话） |

- 15 秒片段包含 2-5 个 shot；单个 shot 时长 3-8 秒。
- 能量曲线要有起伏：禁止全部高潮式强刺激镜头连排，高潮前需要一个相对安静的铺垫镜。

**30 秒片段（长片段模型，如 seedance2.5）**：五段结构等比拉长——0-6s 建立 / 6-12s 引入 / 12-18s 发展 / 18-24s 高潮 / 24-30s 落点留钩；包含 2-5 个 shot，单个 shot 时长 3-10 秒；节奏允许更多铺垫与留白，但能量曲线同样要有起伏。

## 五、结尾档案（片段收尾方式三选一）

每个片段的最后一个 shot 必须明确采用以下一种收尾档案：

1. **收束（Resolve）**：动作完成，状态落地（签完字、门关上）。用于段落/分集结尾。
2. **延续锚点（Extension anchor）**：运动方向仍然活跃（人物走向门口未出门、手伸向电话未接起），便于下一片段从同一状态无缝接续。
3. **悬念定格（Cliffhanger freeze）**：停在张力最高点（反派拿起证据的瞬间、两人对视无人说话）。用于分集结尾钩子。

## 六、声音三层（可选增强）

需要描述声音时按三层组织，**默认不生成字幕、不要配乐说明**：

1. **环境音**：与场景空间匹配（雨声、街道嘈杂、挂钟滴答），有真实距离感。
2. **动作音效**：与画面动作同步（纸张撕裂、钥匙滑落、脚步）。
3. **人声**：对白为自然口语，带呼吸与停顿；内心独白/画外音单独标注。

## 七、画面通用约束后缀（每个视频类 prompt 末尾附加）

保持无字幕，不生成任何文字/字幕/水印/Logo；背景人群为模糊剪影/背影/虚化人群，单个镜头背景人群不超过 5-8 人，防止 AI 复制主角面部生成双胞胎。
